# Logi AI — installeurs

Ce dépôt contient uniquement les installeurs publiés de **Logi AI by LogiProf** (le code source reste privé).

- Téléchargez le dernier `.dmg` dans l'onglet **Releases**.
- Une fois Logi AI installé, les mises à jour se font directement depuis l'application : **Réglages › Mises à jour**.

Chaque paquet de mise à jour est signé ; Logi AI refuse tout paquet qui ne porte pas la signature LogiProf.
