# Logi AI — installeurs

Ce dépôt contient uniquement les installeurs publiés de **Logi AI by LogiProf** (le code source reste privé).

- Dernière version : **0.4.0** — [télécharger Logi.AI_0.4.0_aarch64.dmg](https://raw.githubusercontent.com/logiprof/logiai-releases/main/versions/0.4.0/Logi.AI_0.4.0_aarch64.dmg) (Mac à puce Apple M).
- Installation : ouvrez le .dmg, glissez **Logi AI** dans **Applications**, puis au premier lancement **Réglages Système › Confidentialité et sécurité › Ouvrir quand même**.
- Une fois Logi AI installé, les mises à jour se font directement depuis l'application : **Réglages › Mises à jour**.

Chaque paquet de mise à jour est signé ; Logi AI refuse tout paquet qui ne porte pas la signature LogiProf.
